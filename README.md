# ngb-autosave-patch
(VIBE CODED. USE WITH CAUTIOUS) An Autosave patch for Ninja Gaiden Black native build by Akirahayabusa.   
Press F5 to quicksave and F9 to quickload.   
Use along with this version:https://akirahayabusa.github.io/ngb-hurricane-patch/

从快速存档开始Load from Quicksave: F9/Back（视图键） + RB 或 LS + RS（左右摇杆同时按下）  
手动快速存档Manual Quicksave:	F5/ Back（视图键） + LB
